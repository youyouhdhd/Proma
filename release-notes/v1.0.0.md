# v1.0.0 — Fork 独立版本号起始

- 发布日期：2026-09-06
- 基准上游：`proma-ai/Proma` `7a3721d7`（v0.19.31 之后、Slack Bridge / GPT-6 Astra / Gemini 3 思考深度合入点）

## 版本号策略变更

自本版本起，本 Fork 使用独立版本号，不再跟随上游 `0.19.x`：

- **patch**：缺陷修复与构建改进；
- **minor**：功能新增或大型上游合并；
- **major**：预留重大变更。

每个 Release 的说明都会标注其基于的上游基准，便于对照官方更新。

## 本 Fork 相比上游的定制

- **QuickAsk 临时提问浮窗**：Chat / Agent 内与当前会话完全隔离的短对话，独立选模型与推理档位。
- **自建渠道推理档位**：渠道声明档位并映射为 `reasoning_effort`，与上游 `thinkingLevel`（Gemini 3 深度）并存。
- **飞书卡片渠道名**：卡片底部显示「渠道名 / 模型名」。
- **语言误判修复**：无语言标注代码块中的路径清单不再被 highlight.js 误判为 swift/css/bash。
- **稳定打包方案**：hoisted 布局固定 + Electron 二进制自检 + 一键构建脚本。

完整差异与上游同步记录见 [docs/fork-maintenance.md](../docs/fork-maintenance.md)。
